# 小张帮你蹲 AustinHelpU 宣传图

共 5 张高清 PNG，均为 2880×1800（16:10），另附一张总览预览图。

1. 01-overview.png：产品总览
2. 02-multi-monitor.png：多配置、多门店监控
3. 03-proxy-routes.png：内置代理与节点轮换
4. 04-bark-notifications.png：Mac 提醒设置与 iPhone Bark 到货通知示意
5. 05-menu-bar.png：菜单栏后台运行

建议将图片放入 GitHub 仓库 docs/images 目录，在 README 中按上述顺序展示。

设计参考用户提供的 Word Mac App Store 宣传页，采用统一背景、大标题与应用界面组合；未使用其产品截图或品牌素材。
参考链接：https://apps.apple.com/cn/app/microsoft-word/id462054704?mt=12

应用画面基于 AustinHelpU 0.1.6 的 SwiftUI 视图离线渲染。为拍摄效果加入演示商品、门店、库存、订阅和线路，不代表实时库存或真实查询。
Bark 手机外观及菜单栏面板为排版示意，不是手机实拍或实时推送截图。
原始人物图标沿用用户提供的图片。图中不含用户实际订阅地址、节点凭证、Bark Key 或监控清单。

图中代理功能不承诺解除 Apple 的访问限制；后台监控依赖电脑保持联网且未休眠。

修订版 v2：第 1 张采用指定标题、副标题及四个角标；第 4 张改用“提示音”，左侧截图严格等比例缩放。其余 3 张保持原图。

修订版 v3：第四张手机通知图标使用用户提供的 Bark 原图，仅做尺寸适配；其余四张保持 v2 原图。
