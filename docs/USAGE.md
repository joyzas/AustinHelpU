# AustinHelpU · macOS 预览版 0.1.7

Apple 直营店 iPhone 到店取货监控工具。仅监控和提醒，不包含加购、辅助结账、下单或付款。

## 打开应用

适用于 Apple 芯片 Mac（M1 及更新），macOS 14 或更新版本。

1. 解压安装包，把“AustinHelpU.app”拖到“应用程序”。
2. 双击启动。预览版采用本地 ad-hoc 签名，尚未经过 Apple Developer ID 签名与公证。如被系统拦截，确认来自本次交付后，在系统设置的“隐私与安全性”中选择“仍要打开”。
3. 先点击监控台底部“看看演示效果”，检查布局。演示数据有明确标记，不发送通知，也不参与真实监控。
4. 退出演示，点击“添加监控”，选择机型、容量、颜色和门店，再点击“开始蹲守”。
5. 库存查询需要“应用程序”目录下的 Google Chrome 或 Microsoft Edge。应用启动专用后台浏览器，不读取日常浏览器资料。
6. 系统通知首次使用需授权；可在提醒设置里测试声音、Mac 通知和 Bark 推送。

应用关闭窗口后继续在菜单栏运行；彻底退出请使用菜单栏“退出AustinHelpU”。电脑睡眠、合盖、断网和关机都会影响监控。开启防止自动睡眠仅防止空闲睡眠，不能阻止合盖或手动睡眠。

## 使用订阅代理

1. 在“代理线路”点击“下载官方组件”，从 MetaCubeX/mihomo 官方 GitHub Release 下载，并通过发布信息里的 SHA-256 校验后安装。
2. 如果 GitHub 无法访问，可自行从官方页面下载适配 macOS Apple 芯片的 mihomo，解压后用“手动导入”选择可执行文件。手动导入不验证发布方哈希，需自行核实来源。
3. 输入订阅名称和 HTTPS 订阅地址，点击“添加订阅”。
4. 点击“加载 / 更新节点”。首版接受标准多行 Clash / mihomo YAML 格式（顶层 proxies 列表）；不接受 Base64 通用订阅、仅含 proxy-providers 的配置、YAML 引用和行内 proxies 列表。若不支持，会提示换用 Clash 订阅。
5. 选择参与轮换的节点，可用关键词筛选。多个订阅的节点名称不能重复。
6. 打开“使用专用代理”。默认采用异常时切换，也可开启定时轮换，默认为 5 分钟。
7. 回到监控台开始蹲守。无需启用系统代理或 TUN，也不需要管理员权限。已有系统代理或 TUN 可能影响代理组件自身的联网路径。

节点连通检测仅表示检测地址可达，不保证 Apple 可访问。网站拒绝查询时停止本轮，当前节点按 5 / 10 / 20 / 30 分钟递增冷却；连不通的节点跳过 60 秒。两次真实库存请求至少间隔 2 秒，默认轮次间隔为 30 秒。被拒后至少等待 60 秒，不进行无限即时重试。

切换会关闭软件自己的查询浏览器连接并重建会话，避免复用旧出口；切换节点不一定改变公网 IP，也不能保证消除 Apple 的浏览器校验或频率限制。

## 提醒

- 默认仅在确认有货且由非有货状态变为有货时提醒。
- 可开启持续有货每 5 分钟再次提醒。
- 可设置有货后暂停。
- Bark 需填写 HTTPS 服务器地址和设备 Key。点击保存后再测试。日志显示发送成功仍需在手机确认实际收到。
- 点击 Mac 到货通知或列表中的型号可打开 Apple 商品页面。

商品与门店目录是从参考仓库读取的快照，不保证 Apple 持续销售这些型号，也不包含自动刷新官方商品目录。首版仅支持中国大陆 iPhone 取货，不支持其他地区、其他品类、配送日期、登录启动和自动更新应用。

## 数据与隐私

0.1.6 在代理订阅和提醒设置中加入“凭证与隐私说明”，说明保存内容、应用标识、更新后可能再次授权、拒绝授权的影响，以及订阅和 Bark 的联网用途。现有凭证保存方式保持不变。

系统提示中的 cn.xiaozhang.watch 是本应用保存凭证的标识。本应用仅按自己的标识读取保存的凭证，不查询其他应用的密码。确认本应用身份后，在 macOS 系统弹窗输入 Mac 登录密码并选择“允许”；不要在软件的订阅输入框填写登录密码。拒绝访问会影响相关订阅加载或 Bark 推送。

加载订阅会访问用户配置的订阅服务；启用 Bark 后，商品、门店和提醒内容会发送到用户配置的推送服务器；库存请求通过所选网络或代理访问 Apple。凭证不会上传给软件开发者，也不随安装包分发。

设置及独立代理配置位于用户 Application Support/XiaozhangWatch 中。订阅地址和 Bark 地址保存于 macOS 钥匙串，不写入 settings.json。为启动代理，节点凭证会写入本机权限 0600 的 proxy.yaml；并非所有数据都在钥匙串中。查询浏览器使用本应用专用资料目录。日志只保留最近 500 条，可手动导出。

软件不收集或上传 Apple 账户、登录资料和支付信息。请求只涉及 Apple 查询、用户配置的订阅/代理/Bark、官方组件下载和节点连通检测。

## 源码与构建

源码采用 SwiftUI + Foundation，不需要 Node、Rust 或第三方 Swift 包。包含完整源码、目录快照、测试与本地构建脚本。

在安装了 macOS Command Line Tools 的 Apple 芯片 Mac 上，运行 build.command。脚本自动选择本机 SDK，构建 macOS 14+ arm64 应用并执行 ad-hoc 签名。首次编译 SwiftUI 可能需要较长时间。

## 0.1.4 刷新反馈与干净分发

每个监控结果返回后，结果行显示“刚刚刷新”，刷新图标旋转并短暂高亮，然后恢复检查时间；即使库存状态没变也会触发。失败显示橙色“查询异常 · 结果未确认”，不表示查到库存。遵循 macOS 减少动态效果设置。

安装包只包含应用、源码、公开商品/门店目录和说明，不包含订阅地址、订阅名称、节点池、代理配置、监控清单、Bark 凭证、日志或浏览器资料。全新用户需自行配置；升级用户仍读取自己电脑中已保存的设置，不会清除。公开商品/门店目录只供用户选择，不是已添加的监控列表。
